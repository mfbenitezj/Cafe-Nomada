# Café Nómada ☕

Web demostrativa para una cafetería ficticia, creada con HTML, CSS y JavaScript.

## Ver la web

Cuando termine el despliegue, estará disponible en:

**https://mfbenitezj.github.io/Cafe-Nomada/**

## Incluye
- Diseño responsive para móvil y ordenador.
- Catálogo de ejemplo con fotografías.
- Filtros de productos por categoría.
- Carrito interactivo y cálculo del total estimado.
- Secciones de historia, horario y contacto.
- Preparación de un pedido como mensaje para WhatsApp.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño y estilos.
- `script.js`: carrito, filtros y acciones.

## Personalización
En `script.js`, cambia `WHATSAPP_NUMBER` por el número real con prefijo internacional, sin espacios ni signos. Actualiza en `index.html` la dirección, el correo, el horario y el contenido antes de utilizar la página para un negocio real.

## Importante
Esta es una demo: los datos y precios son ficticios, no procesa pagos y no guarda pedidos en un servidor. Las fotografías y las fuentes se cargan desde servicios externos, por lo que hace falta conexión a Internet para verlas. No utilices la demo como tienda comercial real sin una solución adecuada para gestionar pedidos, datos y pagos.
